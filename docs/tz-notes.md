# ТЗ: что касается вёрстки

Выжимка из ТЗ №UKH-MY/TZ-2 (16.09.2026) — только пункты, влияющие на вёрстку. Бэкенд (1С, роли,
логи, версии документов, предпросмотр) здесь не повторяется.

## Общие правила

- **Всё, что правит админ, не зашито в код** — тексты, картинки, баннеры, их порядок и
  количество. Иначе исправляем бесплатно.
- **Любой элемент может отсутствовать**: удаление фото или описания не ломает блок и не
  удаляет секцию. Каждый блок — 0, 1, N элементов, пустые поля не оставляют дыр.
- **Фото любого размера** подстраиваются под формат: у всех слотов фиксированные пропорции и
  `object-fit: cover`, ресайз и сжатие — на бэке, `srcset` для 2x. Не мылить: без
  `transform: scale` у фото (в текущем «Галерее» фото чёткие только при наведении).
- **Читабельность**: размер шрифта сохранить (в макете — да).
- **Интервал между абзацами** в контенте из редактора: админ выбирает — большой или как между
  строками. Два класса в `.content` + стили визуального редактора Битрикса.
- **Таблицы из Ctrl+C / Ctrl+V** без обёрток: на мобильном горизонтальная прокрутка сама.
- **Кроссбраузерность, скорость**: картинки ниже первого экрана — `loading="lazy"`.

## Уже учтено

- Шапка: логотип — ссылка на главную, меняется через админку (праздничные логотипы, данные
  `logo`); «О холдинге» без ссылки — только раскрывает подменю; подменю по наведению, тапу и
  с клавиатуры; «Войти в ЛК» выделена.
- Подвал: всё из данных; соцсети в новой вкладке.
- Баннеры: слайдер — картинки и видео (видео без звука, по кругу, при «уменьшить движение» не
  запускается само); 0/1/N баннеров и промо не ломают блок.
- Новости на главной: 5 последних, адаптивная сетка; счётчик комментариев ведёт к комментариям
  новости; описание необязательно.
- Акции, корпоративные новости — отдельные блоки на главной (разгрузка слайдера).

## Сделать при вёрстке следующих блоков

- **Поиск**: лупа в шапке с всплывающей длинной строкой; в разделах — строка под названием
  раздела на всю ширину; область поиска зависит от раздела (весь сайт / новости / документы
  по названию и содержимому / справочник). В справочнике — переключатель «не исправлять
  раскладку» (пример: фамилия Кутыш).
- **Хлебные крошки** на всех внутренних страницах.
- **Модальная форма «Предложить тему»** (из подвала): обязательная галочка согласия со ссылкой
  на документ, после отправки — «Спасибо! Ваше обращение передано в редакцию».
- **Ключевые показатели** («В цифрах»): значения, подписи и иконки редактируются, иконки и
  пункты можно скрыть.
- **«Галерея живой заботы. Лидеры месяца»** и **«Фармлидеры»**: название редактируется, место
  под текст «за какие заслуги», клик — в карточку сотрудника; «Фармлидеры» скрыты по
  умолчанию.
- **Новости (раздел)**: группировка по годам, категории и теги, мультимедиа-галерея в
  новости, видео, кнопка «Все новости» под новостью, дата публикации внизу карточки.
- **HR-дайджест**: файлы (pdf), годы, обложка, дата, заголовок; комментарии, лайки, эмодзи;
  ответы под вопросами.
- **Структура, справочник, карточки компаний**: место под текст-описание, фото и видео.
- **Галерея**: годы, альбомы с обложками, фото и видео.
- **Вакансии, Карьерный шанс**: страница, описание раздела, форма отклика.
- **Формы обратной связи** — может быть скрыта админом (не ломает страницу).

## Расхождения ТЗ и макета — уточнить

1. **Новости на главной**: по ТЗ — без описаний, в макете — с описанием. Вёрстка поддерживает
   оба варианта, решает бэк.
2. **Слоган в подвале**: по ТЗ «Здоровье как искусство», в макете «Превращаем заботу о здоровье
   в искусство». Текст из админки — выводится любой.
3. **Пропорции баннеров**: по ТЗ все три баннера пропорциональны, чтобы переставлять между
   слотами. В макете слайдер 1100×500 (2.2:1), промо 480×234/244 (~2:1), на мобильном
   340×300 и 340×200. Картинки обрезаются по `cover`, но для перестановки без потерь
   дизайнеру стоит свести слоты к одной пропорции.
4. **Локализация**: ТЗ — автоопределение языка интерфейса и ручной переключатель; по нашей
   договорённости — только русский. Подтвердить с заказчиком.
