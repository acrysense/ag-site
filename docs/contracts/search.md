## Раскладка

- С 1024: слева сайдбар 350 (разделы с количеством, черта, фильтры, «Сбросить фильтры»),
  справа выдача (заголовок с запросом, «Найдено …», сортировка 240, список, страницы).
- До 1024: в белом блоке — «Результаты поиска», «Найдено …», лента разделов (вкладки, прокрутка
  вбок), «Фильтры · N» и сортировка, список, «Показать ещё». Фильтры — панель на весь экран
  с «Сбросить» и «Показать N результатов».

## Форма и адрес

Вся страница — одна GET-форма (`action` — адрес страницы поиска): запрос, раздел, фильтры,
сортировка и страница — в адресе, ссылкой можно поделиться, «Назад» работает.

```
/search/?q=иван&section=directory&department[]=1&department[]=2&sort=alpha&page=2
```

- `q` и `section` — скрытые поля формы. Разделы: `directory` (Справочник, по умолчанию),
  `news`, `documents`, `vacancies`. Режима «Везде» нет.
- Пустые параметры в адрес не попадают (скрипт чистит форму перед переходом).
- Фильтр с мультивыбором — массив (`name[]`). Период — `…_from`/`…_to` в `YYYY-MM-DD`.
  Числа — только цифры (разряды на экране — пробелами, в форму уходят без них).
- С 1024 фильтр применяется сразу (переход): список с мультивыбором — один раз, когда его
  закрыли; период — по «Применить»; число — когда ушли из поля или нажали Enter.
- До 1024 выбор применяется кнопкой «Показать N результатов». Число считается на лету:
  GET `countUrl` с параметрами формы → `{ "count": 5 }`. Не посчитали — остаётся прошлое.
- «Сбросить фильтры» / «Сбросить» — ссылка `resetUrl` (тот же запрос и раздел без фильтров).
- Смена раздела — ссылка из `sections[].url`: запрос сохраняется, фильтры прошлого раздела —
  нет (у каждого раздела свой набор).

## Что выводит бэк

| Данные | Где | Примечание |
| --- | --- | --- |
| Разделы | `SearchSections items[]` | `text`, `url`, `count`, `current`, `icon` (для ленты: `profile`, `news`, `directory`, `case`); 0 — серый |
| Фильтры раздела | `SearchFilters filters[]` | см. ниже; набор — по разделу |
| Подпись над фильтрами (360) | `sectionLabel` | название раздела |
| Кнопка панели | `countText`, `countUrl` | «Показать 5 результатов» — склонение на бэке, дальше считает скрипт |
| Число выбранных фильтров | `activeFilters` | «Фильтры · 2» |
| Заголовок | `query` | «Результаты поиска «иван»» (на мобильном запрос — только в строке поиска) |
| Сколько найдено | `foundText` | «Найдено 5 сотрудников в Справочнике» — склонение на бэке |
| Сортировка | `sort` (Select) | `name=sort`, `submit`; Справочник — по алфавиту / по релевантности, остальные — по релевантности / по дате |
| Результаты | `items[]` (SearchResult) | 10 на страницу |
| Страницы | `pagination` (Pagination) | с 1024 |
| Показать ещё | `more.url` | до 1024: адрес следующей страницы (`?page=N`), скрипт берёт из неё `[data-search-items]` |
| Пусто | `empty` | `title`, `text`, `resetUrl` (только если есть фильтры), `clearUrl` |
| Запрос в шапке | `header.search.value` | строка поиска показывает запрос |

### Фильтры

| type | Компонент | Поля |
| --- | --- | --- |
| `select` | Select `multiple` + поиск по пунктам | `name` (`department[]`), `placeholder` («Отдел»), `searchPlaceholder` («Найти отдел»), `options[{ value, text, selected }]`, `valueText` («Отдел: 2» — до JS), `url` (если пунктов много — с сервера, как в select.md) |
| `date` | DateRange + Calendar | `nameFrom`, `nameTo`, `from`, `to` (`YYYY-MM-DD`), `placeholder` («Дата публикации») |
| `number` | NumberRange | `label`, `nameFrom`, `nameTo`, `from`, `to`, `placeholderFrom`, `placeholderTo`; во всю ширину |

Наборы (заметки 4734:1835): Справочник — юр. лицо, отдел, должность, город; Новости — дата
публикации, рубрика; Документы — дата, тип файла, папка; Вакансии — зарплата от/до, город,
юр. лицо.

### Результат (SearchResult)

| Поле | Примечание |
| --- | --- |
| `url` | ссылка — вся строка |
| `section` | `directory`, `news`, `documents`, `vacancies` — цвет метки |
| `sectionLabel` | «Справочник» |
| `type` | заглушка без картинки: `person`, `news`, `document`, `other` (страница, ссылка), `vacancy` |
| `image.src`, `image.srcset` | превью 64×64 (2x — 128×128), обрезка по cover; фото сотрудника, картинка новости |
| `titleHtml`, `snippetHtml` | совпадения — в `<mark>`; **текст экранирует бэк** (htmlspecialchars), `<mark>` — единственный тег |
| `meta` | «PDF · 1,2 МБ · Библиотека / Регламенты · обновлено 02.09.2026», «Новости · 08.07.2026» и т. п. |

Фрагмент: с 768 — одна строка с многоточием, до 768 — до двух строк.

## Календарь (Calendar.Range)

Первый клик — начало, второй — конец (раньше начала — меняются местами); предпросмотр при
наведении. Пресеты: Неделя — текущая пн–вс, Месяц — текущий месяц, Год — текущий год (сетка
месяцев; в ней первый клик — месяц целиком, второй — до другого месяца). Повторный клик по
пресету снимает его; клик по дате после пресета — свой период. Сегодня — синяя обводка.
Выбор — черновик до «Применить»; «Сбросить» очищает поле.

**Кнопок пресетов в макете нет** (у компонента есть режимы Week/Month/Year) — сделан ряд
«Неделя / Месяц / Год» над месяцем в стиле вкладок мобильного поиска. Уточнить у дизайнера.

## Состояния

- Раздел без результатов — серый (и в меню, и во вкладках), по нему можно перейти.
- Пусто: круг с лупой, «По вашему запросу ничего не найдено», подсказка, «Сбросить фильтры»
  (если фильтры выбраны) и «Очистить поиск».
- Длинные названия переносятся, фрагмент обрезается многоточием.
- Загрузка: страница приходит целиком; «Показать ещё» — в состоянии загрузки; не загрузилось —
  обычный переход по ссылке.
