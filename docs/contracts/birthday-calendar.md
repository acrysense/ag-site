# Контракт: страница «Дни рождения»

Черновик для согласования с бэкендом (Битрикс). Страница: `app/pages/birthdays.html`.
Вёрстка: календарь — `app/components/sections/birthdays/BirthdayCalendar`, боковая карточка —
`app/components/sections/shared/Birthdays` (та же, что на главной), крошки —
`components/Breadcrumbs`, фильтры — `components/Select`. Витрина:
`/dev/ui.html#story=birthday-calendar`.

Макет: Figma, 1920 — `4704:1019`, 360 — `4706:1361`. С главной сюда ведёт заголовок блока
«День рождения».

## Раскладка

- С 1280: календарь слева, справа карточка 385 «Скоро праздник» (сегодня + следующие 7 дней).
- 1024–1279: карточка под календарём во всю ширину, «Сегодня» и «Следующие» — двумя колонками.
- До 1024: список дней вместо сетки, карточки нет (в макете 360 её нет).

## Фильтры

Обычная GET-форма: `month` (1–12) и `company` (id юрлица, пусто — все). Выбор в списке сразу
отправляет форму, страница перезагружается с новым месяцем; есть скрытая кнопка «Показать» —
для клавиатуры и без JS. `bitrix_sessid` не нужен: форма ничего не меняет.

## Что выводит бэк

Заголовок «Дни рождения» и месяц отдельно (`titleMuted`, серым). Дни — **целыми неделями с
понедельника**, включая дни соседних месяцев (как в макете: 31 авг … 4 окт).

| Поле дня | Где в разметке | Примечание |
| --- | --- | --- |
| Дата | `time.birthday-calendar__num[datetime]` | `YYYY-MM-DD`, число и месяц в родительном («сентября») |
| Короткий месяц | `.birthday-calendar__month-short` | только у дней соседнего месяца: «авг», «окт» |
| День недели | `.birthday-calendar__weekday` | «понедельник»; на десктопе виден только скринридеру |
| Признаки | классы `is-weekend`, `is-past`, `is-today`, `is-other-month` | считает бэк по дате сервера |
| Люди | `.birthday-calendar__person` | ФИО, юрлицо, фото, ссылка на карточку сотрудника |

Сетка на десктопе: ряд по высоте самого загруженного дня (не ниже 121), все люди дня
видны. ФИО и юрлицо в одну строку, длиннее — «…». Фото — квадрат, круглая маска: 20px на
десктопе, 40px на мобильном, для 2x — **80×80**. Нет фото — значок подарка.

Мобильный список показывает только дни этого месяца, где есть именинники. Совсем нет —
`empty: true` и текст «В этом месяце дней рождения нет» (правится, `emptyText`).

Прошедшие дни бледнее, выходные — фон BG.Info, сегодня — BG.Violet и плашка «Сегодня».
