# Контракт: тост (всплывающее сообщение)

Один тост на сайт — по киту (Figma: Quick info `2543:906`): тёмная плашка внизу по центру (на
мобильном — над нижней навигацией), 2,5 с, новый заменяет текущий, скринридер его читает. Вид в
витрине: `/dev/ui.html#story=toast`. Рисует его JS — разметку плашки бэку выводить не нужно.

Виды (`type`): `ok` — галочка (успех), `error` — крестик (ошибка), `info` — нейтральный.

## Вызвать тост

**1. Из JS** (обработчик AJAX, свой скрипт) — событие на `document`:

```js
document.dispatchEvent(new CustomEvent('ui:toast', { detail: { text: 'Документ сохранён', type: 'ok' } }))
```

**2. Из шаблона** — заготовка в разметке. Покажется сама, когда окажется на странице: сразу после
загрузки (например, после отправки формы с перезагрузкой) или когда придёт в ответе AJAX и
будет вставлена в страницу:

```html
<div hidden data-module="Toast" data-path="components" data-toast="ok">Заявка отправлена</div>
```

Текст выводится как текст (HTML в нём не сработает) — экранировать его всё равно нужно, как
любой вывод. `data-toast` не указан — `info`. Пустой текст — тост не показывается.

Куда ставить заготовку — не важно (лучше в конец `<body>` или в блок, который пришёл по AJAX):
после показа элемент удаляется.

## Где уже есть

- «Скопировать ссылку» (новость, документы): `ok` «Ссылка скопирована», если буфер недоступен —
  `error` «Не удалось скопировать ссылку». Бэку ничего делать не нужно.

Ошибки и успех форм тостом не показываются — у форм свои сообщения в самой форме
(`docs/contracts/form.md`).
