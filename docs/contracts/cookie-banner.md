# Контракт: согласие на cookie

Вёрстка: `app/components/layouts/CookieBanner` (подключён на всех страницах). Витрина:
`/dev/ui.html#story=cookie-banner`. Макет: Figma `4711:32225` (карточка 420).

## Поведение

- Не модальное окно: левый нижний угол (на мобильном — во всю ширину над нижней
  навигацией), без затемнения, фокус не перехватывает — сайтом можно пользоваться сразу.
  В макете карточка на затемнении; решено без него, поэтому у карточки тень и рамка.
- «Принять» / «Отклонить» пишут cookie `ag_cookie_consent` = `accepted` / `declined`
  (`Max-Age` год, `Path=/`, `SameSite=Lax`, на https — `Secure`) и скрывают баннер.
- На `document` уходит событие `cookie-consent` (`detail.choice`) — по нему подключать
  счётчики и аналитику, которые требуют согласия.

## Что делает бэк

- Не выводит баннер, если cookie `ag_cookie_consent` уже есть. Если страница отдана из кеша
  с баннером — скрипт скроет его сам.
- Тексты и ссылка на политику — `site.cookies` (правятся в админке); имя cookie — там же.
- При «Отклонить» не ставить необязательные cookie (аналитика и т. п.).
