# Контракт: согласие на cookie

Вёрстка: `app/components/layouts/CookieBanner` (подключён на всех страницах). Витрина:
`/dev/ui.html#story=cookie-banner`.

## Поведение

- Не модальное окно: левый нижний угол (на мобильном — во всю ширину над нижней
  навигацией, а где её нет, как на входе, — у низа экрана), без затемнения, фокус не перехватывает — сайтом можно пользоваться сразу.
- «Принять» / «Отклонить» пишут cookie `ag_cookie_consent` = `accepted` / `declined`
  (`Max-Age` год, `Path=/`, `SameSite=Lax`, на https — `Secure`) и скрывают баннер.
- Счётчики и всё, что ставит необязательные cookie, бэк выводит **выключенными** — скрипт
  включит их сам после «Принять» и на каждой следующей странице, если согласие уже есть:

  ```html
  <script type="text/plain" data-cookie-consent src="https://mc.yandex.ru/metrika/tag.js" async></script>
  <script type="text/plain" data-cookie-consent>
    /* код счётчика */
  </script>
  ```

  Все атрибуты, кроме `type` и `data-cookie-consent`, переносятся (`src`, `async`, `defer`, `id`
  …); нужен другой тип (`module`) — `data-cookie-type="module"`. Без согласия эти теги не
  выполняются.
- Передумать можно: любой элемент с `data-cookie-settings` (например, ссылка «Настройки cookie»
  в подвале) снова показывает баннер. Новый выбор перезаписывает cookie.
- На `document` уходит событие `cookie-consent` (`detail.choice`) — если что-то удобнее
  подключать самим.

## Что делает бэк

- Не выводит баннер, если cookie `ag_cookie_consent` уже есть. Если страница отдана из кеша
  с баннером — скрипт скроет его сам.
- Тексты и ссылка на политику — `site.cookies` (правятся в админке); имя cookie — там же.
- При «Отклонить» не ставить необязательные cookie (аналитика и т. п.) и удалить уже
  поставленные ими (если согласие отозвали через «Настройки cookie»).

## Без мелькания при загрузке

Баннер выводится с атрибутом `hidden`: скрипт показывает его, только если cookie с выбором ещё
нет. Раньше он выводился видимым и прятался скриптом — при перезагрузке успевал мелькнуть.
Лучше всего, если бэк вообще не выводит баннер, когда cookie уже есть.
