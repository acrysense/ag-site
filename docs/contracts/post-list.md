# Контракт: «Акции» и «Корпоративные новости» на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/PostList` —
один компонент для обоих блоков. Витрина: `/dev/ui.html#story=post-list`.

Макет: Figma, главная 1920 — узел `4615:42853`, 360 — `4865:1354`.

## Что выводит бэк

Заголовок, ссылка на раздел и список пунктов «картинка + заголовок».

- На десктопе по 4 пункта на странице, стрелки листают страницы. Пунктов 4 и меньше — стрелок
  нет. На мобильном — первые 4, без листания.
- Нет пунктов — блок не выводится, соседние в ряду занимают его место.

| Поле | Где в разметке | Обязательно | Примечание |
| --- | --- | --- | --- |
| Заголовок блока | `.post-list__title` | да | правится в админке |
| Ссылка на раздел | `.post-list__title a[href]` | нет | |
| Ссылка на пункт | `.post-list__link[href]` | да | |
| Заголовок пункта | `.post-list__text` | да | до 2 строк на мобильном, 3 на десктопе, дальше «…» |
| Картинка | `.post-list__image` | нет | нет картинки — только текст |

## Картинки

Квадрат, `object-fit: cover`: 60px на мобильном, 80px на десктопе, для 2x — **160px**. Та же
пропорция 1:1, что у карточек «Новостей холдинга»: одну и ту же квадратную обложку можно
ставить в оба блока.
