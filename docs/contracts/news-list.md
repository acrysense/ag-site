# Контракт: раздел новостей

Страница: `app/pages/news.html`. Вёрстка: лента — `sections/news/NewsList`, фильтры —
`sections/news/NewsFilters`, вертикальный баннер — `sections/shared/SideBanner`, карточка —
`sections/shared/NewsCard` (та же, что на главной), страницы — `components/Pagination`.
Витрина: `/dev/ui.html#story=news-list`, `#story=news-filters`, `#story=pagination`.

Макет: Figma, 1920 — `4467:758`. Мобильного макета нет — сделано нами (ниже).

## Раскладка

- С 1024: слева колонка 350 (фильтры, под ними баннер 350×800), справа лента.
- До 1024: крошки, фильтры строками «таблеток» (прокрутка вбок внутри блока, выбранная
  прокручивается в видимую часть), заголовок и сортировка, сетка, страницы. Баннера нет.
- Сетка: мобильный — 2 колонки, планшет — от 200px, десктоп — от 240px (на 1920 — 4 по 280).

## Что выводит бэк

| Данные | Где | Примечание |
| --- | --- | --- |
| Название раздела | `h1.news-list__title` | |
| Сортировка | `components/SortMenu` | `sort { id, label, options [{ text, url, current }] }`: текущий порядок текстом со стрелкой, по клику список вариантов (ссылки GET, текущий — с галочкой), до 768 — нижний лист; один вариант — просто текст |
| Карточки | `.news-list__item` | поля — как на главной (docs/contracts/news-feed.md) |
| Категории | `a.news-filters__link` | текущая — `aria-current="page"` |
| Годы | `a.news-filters__chip` | текущий — `aria-current="true"` |
| Страницы | `components/Pagination` | `prev`, `next`, `pages[{ number, url, current, far, gap }]`, `total` |
| Баннер | `sections/shared/SideBanner` | картинка 350×800 (2x — 700×1600), `alt` обязателен, ссылка |

- Всё — обычные ссылки (GET), без JS. Порция — 20 карточек (5 рядов по 4).
- `far` — страница, которую на мобильном не показываем: оставить первую, последнюю и соседние
  с текущей, между ними `gap`. Одна страница — навигации нет, только «Всего».
- Пустой раздел — «В этом разделе пока нет новостей» (`emptyText`).

## Расхождения макетов

Крошки на этой странице в макете 14px и через 40 от содержимого, на «Днях рождения» — 12px и
через 20. Сделано одним компонентом, как на «Днях рождения»; уточнить у дизайнера.
Тень карточки фильтров в макете другая (0 4 25, 3%) — взята общая тень блоков.
