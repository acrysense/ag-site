# Контракт: шапка сайта

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/layouts/Header`,
поиск — `app/components/layouts/SiteSearch` (docs/contracts/site-search.md). Витрина:
`/dev/ui.html#story=header`.

Мобильное меню по бургеру — отдельный блок (docs/contracts/main-menu.md).

## Что выводит бэк

| Поле | Где в разметке | Примечание |
| --- | --- | --- |
| Логотип с названием | `.header__logo source[srcset]` (с 1280), `.header__logo img[src]` (уже) | одна картинка «знак + название»: `logotype-desktop.svg` (с 1280, в строку) и `logotype-mobile.svg` (190×40, полное название в две строки; не хватает места — уменьшается сама). Меняется через админку (праздничные логотипы) — две картинки |
| Ссылка на главную | `.header__logo-link[href]` | вся картинка (`aria-label` «На главную») |
| Поиск | `form.search-field[action]`, `input[name]` | GET на страницу поиска, поле `q` |
| Меню | `.menu__item` | из компонента меню Битрикса, 2 уровня |
| Текущий раздел | `aria-current="page"` на `.menu__link` / `.menu__sublink` | ставит бэк на пункт текущего раздела |
| Пользователь | `.header__user[href]`, `.header__avatar img` | фото 30×30 (60×60 для 2x), имя — для скринридера |
| Гость | `.header__login[href]` | две надписи: `.header__login-text` «Войти в ЛК» (с 1024) и `.header__login-text--short` «Войти» (до 1024) |
| Меню под аватаром | `.user-menu__link[href]`, `.user-menu__divider` | пункты: подпись, ссылка, значок из спрайта; разделитель; у выхода `data-modal-open` — окно «Выйти из аккаунта?» (без JS — переход по ссылке). Пунктов нет — аватар ведёт в ЛК |

Пункт с подменю — ссылка и отдельная кнопка-стрелка `[data-submenu-toggle]`: на десктопе
подменю открывается и наведением, на тач-устройствах и с клавиатуры — стрелкой.

Меню под аватаром — разделы личного кабинета в его порядке («Моя страница», «Учебный портал»,
«Коэффициент», «Пакеты», «Мотивация», «Конкурсы»), разделитель, «Настройки», «Выйти». Состав
правит админ; раздел ERP (Дашборд, Аптеки, Менеджеры…) сюда не выводится.

Панель администратора `#bx-panel` шапке не мешает: шапка не закреплена при прокрутке.

## Узкий десктоп (1024–1279)

Длинный логотип с названием в строку не помещается рядом с поиском и быстрыми ссылками —
выводится мобильный (название в две строки), крупнее: 47 по высоте. Имя пользователя — до 200px,
длиннее обрезается «…».

## Гость и вошедший

Шапка, меню под аватаром и мобильное меню зависят от входа. Бэк выводит одно из двух:

- **гость** — в шапке «Войти в ЛК»; в мобильном меню вместо профиля карточка входа
  (`.main-menu__login`: заголовок, пояснение, кнопка «Войти в ЛК»), разделов CRM и кабинета нет;
  плитки портала и «Присоединяйтесь» — как у вошедшего;
- **вошедший** — аватар с меню (разделы кабинета, «Настройки», «Выйти»), в мобильном меню профиль,
  CRM (по роли) и кабинет.

В демо: `index.html` — гость, `index-user.html` — вошедший.
