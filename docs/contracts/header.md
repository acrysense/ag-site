# Контракт: шапка сайта

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/layouts/Header`,
поиск — `app/components/layouts/SiteSearch` (docs/contracts/site-search.md). Витрина: `/dev/ui.html#story=header`.

Макет: Figma, PC.HEADER.v2 — `4652:8752`, 360.HEADER — `4865:1334`, выпадающее меню —
`4615:43188`. Мобильное меню по бургеру (360.MainMenu v2 — `4558:842`) — отдельный блок.

## Что выводит бэк

| Поле | Где в разметке | Примечание |
| --- | --- | --- |
| Название сайта | `.header__title--full` | десктоп, одна строка, верхний регистр задаёт CSS |
| Короткое название | `.header__title--short` | мобильный, в макете «Корпоративный сайт холдинга» |
| Ссылка на главную | `.header__brand[href]` | логотип и название — одна ссылка |
| Поиск | `form.search-field[action]`, `input[name]` | GET на страницу поиска, поле `q` |
| Меню | `.menu__item` | из компонента меню Битрикса, 2 уровня |
| Текущий раздел | `aria-current="page"` на `.menu__link` / `.menu__sublink` | вид текущего пункта в макете не нарисован |
| Пользователь | `.header__user[href]`, `.header__avatar img` | фото 30×30 (60×60 для 2x), имя — для скринридера |
| Гость | `.header__login[href]` | «Войти в ЛК» |
| Меню под аватаром | `.user-menu__link[href]`, `.user-menu__divider` | пункты: подпись, ссылка, значок из спрайта; разделитель; у выхода `data-modal-open` — окно «Выйти из аккаунта?» (без JS — переход по ссылке). Пунктов нет — аватар ведёт в ЛК |

Пункт с подменю — ссылка и отдельная кнопка-стрелка `[data-submenu-toggle]`: на десктопе
подменю открывается и наведением, на тач-устройствах и с клавиатуры — стрелкой.

ссылками — выводится короткое в две строки, как на мобильном (`titleShort`). Имя
пользователя — до 200px, длиннее обрезается «…».
