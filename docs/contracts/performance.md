# Контракт: картинки, шрифты, иконки — скорость загрузки

Общие правила для всех блоков (поля и размеры каждого слота — в контрактах блоков). Всё ниже —
обычные атрибуты и файлы в шаблоне Битрикса, без скриптов.

Замер Lighthouse на демо (production-сборка, мобильный / десктоп), 2026-10-01: новости 99 / 98,
журнал 85 / 99, главная 76 / 97; сдвигов вёрстки (CLS) нет, SEO и best practices — 100. Главную на
мобильном держит шрифт Inter (353 КБ, см. ниже).

## Картинки

- **Формат — WebP.** Включить конвертацию в настройках главного модуля (или отдавать WebP при
  ресайзе). Вёрстка принимает любой формат. Качество около 80.
- **Размер — под слот.** `CFile::ResizeImageGet` до размера слота из контракта блока; для экранов
  с плотностью 2x — вторая версия вдвое больше в `srcset` (`… 1x, … 2x` или с `w` и `sizes`, как
  в разметке блока). Оригиналы из админки на страницу не выводить.
- **`width` и `height`** — как в разметке (пропорция слота), сдвигов при загрузке не будет.
- **Первая картинка первого экрана** — `fetchpriority="high"`, без `loading="lazy"`: на главной это
  первый слайд баннеров. Остальные слайды и всё ниже первого экрана — `loading="lazy"`.
- Пока картинка грузится, под ней светлая плашка (цвет скелетона) — задано в CSS, бэку ничего
  не нужно.

## Шрифты

- В `<head>` — предзагрузка шрифта заголовков (он виден в шапке сразу):
  `<link rel="preload" href="…/fonts/RFRufo/RFRufo-Bold.woff2" as="font" type="font/woff2" crossorigin>`
  и то же для `RFRufo-Regular.woff2`.
- Пока шрифт грузится, текст виден системным (`font-display: swap`); для заголовков подобраны
  узкие системные шрифты, чтобы строки не перестраивались.
- **Открыто:** Inter сейчас целиком (353 КБ, все языки) — его стоит заменить облегчёнными файлами
  только с кириллицей и латиницей (~2 × 40 КБ).

## Иконки

- Спрайт — файл `assets/icons/sprite.svg` из сборки, кладётся в шаблон как есть. Иконка —
  `<svg class="icon …"><use href="<?=SITE_TEMPLATE_PATH?>/assets/icons/sprite.svg#icon-имя"></use></svg>`.
- На `<html>` — `data-icons="<?=SITE_TEMPLATE_PATH?>/assets/icons/sprite.svg"`: по нему иконки
  находит JS (подсказки поиска, календарь, комментарии).
- Предзагрузку спрайту не ставить: для `<use>` браузер её не использует и качает файл дважды.

## Прочее

- Фавикон: `<link rel="icon" href="/favicon.svg" type="image/svg+xml">` (пока — знак из логотипа).
- `robots.txt` и описание страниц (`<meta name="description">`) — из SEO-модуля Битрикса; портал
  открыт без входа, страницы индексируются (закрыты только ЛК и ERP).
