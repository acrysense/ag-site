# Контракт: растянутый баннер на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/WideBanner`,
карусель — `app/components/components/Carousel`. Витрина: `/dev/ui.html#story=wide-banner`.

Макет: Figma, главная 1920 — узел `4617:43487`, 360 — `4865:40484`. Стоит после «Новостей
холдинга».

## Что выводит бэк

Список слайдов-картинок. Текст — в самих картинках, поэтому `alt` обязателен (заполняет админ).

- Один слайд — ни стрелок, ни точек. Нет слайдов — блок не выводится.
- На десктопе листают стрелки, на мобильном — точки и свайп (так в макетах).

| Поле | Где в разметке | Обязательно | Примечание |
| --- | --- | --- | --- |
| Ссылка | `.wide-banner__link[href]` | нет | без ссылки картинка не кликабельна |
| Картинка десктопа | `<source media="(min-width: 768px)">` | да | 1600×340 (4.7:1), для 2x — 3200×680 |
| Картинка мобильного | `.wide-banner__image` | нет | 340×190 (1.8:1), для 2x — 680×380; нет — берётся десктопная с обрезкой по краям |
| alt | `.wide-banner__image[alt]` | да | текст с баннера |

Картинки обрезаются по `object-fit: cover`: слот держит пропорцию при любом размере файла.

## Автолистание и анимация

- `data-carousel-autoplay` — интервал в секундах (поле админки «Автолистание, с»; по умолчанию 5,
  `0` — выключено). Листает по кругу; отсчёт начинается заново после любого перелистывания.
- Стоит, пока на карусели мышь (на телефоне — палец) или фокус с клавиатуры, пока карусель не
  видна (прокручена за экран, вкладка в фоне) и при «уменьшить движение» в системе.
- Переход — параллакс (класс `carousel--parallax`): картинка в кадре едет медленнее кадра.
  Только CSS, бэку ничего не нужно. В Firefox и при «уменьшить движение» — обычное листание.
