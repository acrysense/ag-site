# Контракт: баннеры на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/HeroBanners`,
карусель — `app/components/components/Carousel`. Витрина: `/dev/ui.html#story=hero`.

Макет: Figma, главная 1920 — узел `4615:42835`, 360 — `4865:1335`.

## Что выводит бэк

Слайдер (картинки и видео вперемешку) и промо-баннеры справа (на мобильном — под слайдером).

- Один слайд — листать нечего: стрелок и точек нет в разметке.
- Нет промо — слайдер во всю ширину. Нет слайдов — только промо. Нет ничего — блок не
  выводится.
- Текст баннеров — в самих картинках, поэтому `alt` обязателен (заполняет админ).
- У слайда две картинки: для десктопа и для мобильного (`<picture>`). Мобильной нет — берётся
  десктопная.
- Видео: без звука, по кругу, играет только видимый слайд; при «уменьшить движение» не
  запускается само (показывается `poster`).

## Пропорции

Все слоты — фиксированная пропорция и `object-fit: cover`: картинка любого размера не ломает
блок.

**Десктоп (с 768): у слайда и промо одна пропорция 2.2:1** — десктопные картинки
взаимозаменяемы, любую можно поставить в любой слот без обрезки. На 1920 слайд ~1067×485,
промо ~509×231 (в макете было 1100×500 и 480×239 — сведено к одной пропорции по
согласованию с дизайнером). Колонки считаются формулой, пропорция держится на любой ширине.

| Слот | Десктоп (с 768) | Мобильный (до 768) |
| --- | --- | --- |
| Слайд | 2.2:1, для 2x — 2200×1000 | своя картинка 340×300, для 2x — 680×600 |
| Промо | 2.2:1, для 2x — 1100×500 | своя картинка 340×200 (680×400), **необязательна**: нет — десктопная целиком, 340×155 |

У промо, как у слайда, две картинки: `image.desktop` (обязательна) и `image.mobile`.

## Автолистание и анимация

- `data-carousel-autoplay` — интервал в секундах (поле админки «Автолистание, с»; по умолчанию 5,
  `0` — выключено). Листает по кругу; отсчёт начинается заново после любого перелистывания.
- Встаёт на паузу, пока на карусели мышь (на телефоне — палец) или фокус с клавиатуры, пока
  карусель не видна (прокручена за экран, вкладка в фоне); после паузы досчитывает остаток. При
  «уменьшить движение» в системе выключено.
- Активная точка-полоска заполняется за время до следующего слайда и замирает на паузе. Без
  автолистания — сплошная, как в макете. Точки создаёт JS, бэку ничего не нужно.
- Переход — параллакс (класс `carousel--parallax`): картинка в кадре едет медленнее кадра.
  Только CSS, бэку ничего не нужно. В Firefox и при «уменьшить движение» — обычное листание.
- Видео в слайде не дожидается конца ролика: через интервал слайд листается.
