# Контракт: баннеры на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/HeroBanners`,
карусель — `app/components/components/Carousel`. Витрина: `/dev/ui.html#story=hero`.

Макет: Figma, главная 1920 — узел `4615:42835`, 360 — `4865:1335`.

## Что выводит бэк

Слайдер (картинки и видео вперемешку) и промо-баннеры справа (на мобильном — под слайдером).

- Один слайд — листать нечего: стрелок и точек нет в разметке.
- Нет промо — слайдер во всю ширину. Нет слайдов — только промо. Нет ничего — блок не
  выводится.
- Текст баннеров — в самих картинках, поэтому `alt` обязателен (заполняет админ).
- У слайда две картинки: для десктопа и для мобильного (`<picture>`). Мобильной нет — берётся
  десктопная.
- Видео: без звука, по кругу, играет только видимый слайд; при «уменьшить движение» не
  запускается само (показывается `poster`).

## Пропорции

Все слоты — фиксированная пропорция и `object-fit: cover`: картинка любого размера не ломает
блок, но обрезается по краям.

| Слот | 1920 | 360 |
| --- | --- | --- |
| Слайд | 1100×500 (2.2:1) | 340×300 (~1.13:1) |
| Промо | 480×239 (~2:1) | 340×200 (1.7:1) |

По ТЗ баннеры должны переставляться между слотами. На десктопе слайд и промо близки (2.2 и 2),
но не равны: при перестановке срежется ~5% по бокам. Чтобы менять без потерь, дизайнеру стоит
свести слоты к одной пропорции — вёрстка поменяется одной строкой на слот.
