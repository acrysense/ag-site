# Контракт: библиотека документов

Черновик для согласования с бэкендом (Битрикс). Страница: `app/pages/documents.html`, блоки —
`app/components/sections/documents/*`, общие — `components/FileType`, `components/Tooltip`,
`components/Toast` (`utils/toast.js`), `components/CopyLink`. Витрина:
`/dev/ui.html#story=documents-list` (и `document-row`, `documents-folders`, `documents-filters`).

Макет: Figma, страница 1920 — `4526:83`; компоненты и состояния — `4526:29698` (поведение —
`4531:543`). Мобильного макета нет — наше.

## Страница

Хлебные крошки, затем сетка `page-columns page-columns--start`:

1. `page-columns__aside`: `DocumentsFolders` (папки) и `DocumentsFilters` (фильтры). До 1024
   папки — плашка «Папки · текущая» над списком, фильтры — панель на весь экран.
2. `DocumentsList` (класс `page-columns__main`) — заголовок, поиск, чипы, строки, страницы.

## Папки (`DocumentsFolders`)

| Поле | Что это |
| --- | --- |
| `title` | «Папки» |
| `current` | название текущей папки — для мобильной плашки |
| `items[]` | `title`, `url`, `count`, `current`, `expanded`, `children[]` (те же поля, вложенность любая) |

- `count` — число документов в папке **с подпапками и с учётом активных фильтров**.
- Шеврон есть только у папок с подпапками; ветку текущей папки бэк выводит раскрытой
  (`expanded`), остальные свёрнуты. Раскрытие не запоминается.
- «Все документы» — обычный пункт первого уровня.

## Фильтры и адрес

Обычная GET-форма на адрес текущей папки. С 1024 применяется сразу при выборе, до 1024 — кнопкой
«Показать N документов» (число — `countUrl`, как у поиска и вакансий: ответ `{ "count": N }`).

| Поле | Что это |
| --- | --- |
| `groups[]` | `title`, `name` (`company[]`, `year[]`), `variant` (`chips` — «таблетки», как годы), `moreText`, `options[{ value, text, count, checked, extra }]` |
| `hidden[]` | что сохранить в адресе: папка, сортировка, поисковый запрос |
| `resetUrl` | адрес папки без фильтров |

- Внутри группы — «ИЛИ», между группами — «И». Фильтры работают внутри текущей папки.
- `count` у пункта — сколько документов останется при выборе; 0 — пункт неактивный.
- `extra` — пункт за «Показать ещё N» (бэк отмечает пункты после первых 6; выбранные не прячет).
- Выбранные фильтры дублируются над списком чипами: `chips[{ text, url }]`, где `url` — адрес
  без этого фильтра, `chipsResetUrl` — «Сбросить всё». Только ссылки, без JS.

## Список (`DocumentsList`)

| Поле | Что это |
| --- | --- |
| `title`, `count` | папка и число документов в ней (с фильтрами); в поиске — «Поиск по документам» без числа |
| `sort` | SortMenu: «Новые в начале», «Старые в начале», «По названию» — ссылки с параметром |
| `search` | `action`, `name` (`q`), `value`, `placeholder`, `hidden[]` (фильтры, сортировка) |
| `foundText` | «Найдено: 2» — в поиске |
| `filtersId`, `activeFilters` | кнопка «Фильтры · N» до 1024 |
| `items[]` | строки, см. ниже |
| `empty` | `title` («Документы не найдены» / «В этой папке пока нет документов»), `text`, `resetUrl`, `resetText` |
| `pagination` | `Pagination` (как в новостях), `total` — «Всего: N» |

Поиск — по названию во всей библиотеке (не только в папке) с учётом фильтров, от 2 символов.
Сейчас это GET-форма (Enter или лупа). В макете — «по мере ввода»: для этого нужен ответ сервера
без перезагрузки страницы — вопрос к бэку (см. open-questions).

## Строка (`DocumentRow`)

| Поле | Что это |
| --- | --- |
| `type` | `pdf`, `doc` (.doc/.docx), `xls` (.xls/.xlsx/.csv), `ppt` (.ppt/.pptx), `zip` (.zip/.rar/.7z); другое — серый значок |
| `typeText` | подпись значка, если не совпадает с `type` (`DOCX`, `RAR`) |
| `title` | название; полное — в подсказке браузера (`title`), в строке — до 2 строк |
| `titleHtml` | в поиске: название с совпадением в `<mark>`; **текст экранирует бэк**, разрешён только `<mark>` |
| `url`, `newTab` | открыть файл (клик по строке или названию); `newTab` — для PDF в новой вкладке |
| `company` | компания холдинга |
| `path` | в поиске: путь к папке («Положения / Оплата труда»), выводится перед компанией |
| `size` | «1,2 МБ», «214 КБ» |
| `date`, `dateText` | `2026-09-12`, `12.09.2026` — дата обновления (загрузки) |
| `uploader` | `name`, `meta` («Загрузила 05.09.2026» — род глагола по сотруднику), `photo`, `url` (профиль) |
| `shareUrl` | постоянная ссылка на документ в библиотеке (не на временный файл), открывается только вошедшим |
| `downloadUrl` | скачать файл (атрибут `download`) |

- «Скопировать ссылку» — `CopyLink` с `data-copy-toast`: галочка на кнопке 2 с и тост внизу
  экрана «Ссылка скопирована». Не скопировалось — сообщение только для скринридера.
- Нет автора — колонка пустая; нет размера — ячейка пустая.
- Колонки (с 1280): «Название», «Размер», «Обновлён», «Загрузил». Уже — размер и дата под
  названием, колонки «Загрузил» нет.
- Фото автора — 30×30, для 2x — 60×60 (ресайз на бэке).
