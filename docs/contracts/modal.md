# Контракт: модальное окно (Modal)

Общий компонент: `app/components/components/Modal`. Витрина: `/dev/ui.html#story=modal`.

## Вид

- С 768 — карточка по центру: 420 (`size: s`), 480 (`m`), 560 (`l`), поля 32 (у «успеха» 40).
- До 768 — шторка снизу, крестик в круге 36.
- Фон — затемнение с размытием. Не помещается по высоте — шапка на месте,
  тело прокручивается (SimpleBar, общая синяя полоса).
- Варианты: обычный (заголовок и крестик), `center` — по центру с иконкой (`icon: success`),
  `confirm` — подтверждение без крестика (кнопки: на мобильном друг под другом, на
  десктопе в ряд).
- На весь экран до 768 — класс `modal--full` (проп `full`): шапка 56, без скругления, выезжает
  снизу, как шторка. Кнопки внизу — в обёртке `<div class="modal__bar">`: она закреплена у
  нижнего края, содержимое прокручивается под ней. Обёртка — прямой потомок блока на всю высоту
  (тело окна, форма `modal__form` или своя раскладка окна). С 768 окно обычное, по центру.
  Сейчас так — окна карьеры (вакансия, заявка, «Заявка принята»); любое другое окно
  переводится тем же классом.

## Разметка

```hbs
{{#> components/Modal/Modal props=(obj id="suggest" title="Предложить тему" size="l")}}
    …содержимое… <div class="modal__actions">…кнопки…</div>
{{/components/Modal/Modal}}
```

- Открыть: любая кнопка `data-modal-open="<id>"` или событие `modal:open` на окне.
- Закрыть: `data-modal-close`, Escape, нажатие по фону, событие `modal:close`.
- Фокус — внутрь окна (элемент с `autofocus`, иначе первая кнопка или поле), при закрытии —
  обратно на кнопку, которая открыла.
- Окно поверх окна работает: прокрутка страницы снимается, только когда закрыто последнее.
- Форма с несохранёнными изменениями спрашивает подтверждение закрытия (окно
  `data-modal-discard`, одно на странице).

## Выход из аккаунта

Подтверждение — это `Modal` (`variant: confirm`, `size: s`). На телефоне — шторка, на десктопе —
окно по центру в стиле остальных. Фокус — на «Отмена».
