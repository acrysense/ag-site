# Контракт: блок «Аптека групп в цифрах» на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/Stats`.
Витрина: `/dev/ui.html#story=stats`.

Макет: Figma, главная 1920 — узел `4857:2701`, 360 — `4865:1438`.

## Что выводит бэк

Заголовок и список пунктов «число + подпись». Всё правит админ; скрытый пункт бэк не выводит.
Нет пунктов — блок не выводится. Пунктов может быть сколько угодно, в макете 3: на десктопе
они делят ширину поровну.

| Поле | Где в разметке | Обязательно | Примечание |
| --- | --- | --- | --- |
| Заголовок | `.stats__title` | да | как обычный текст; на 1920 верхний регистр делает стиль |
| Число | `.stats__value` | нет | строка как есть: «400+», «2000+» |
| Подпись | `.stats__caption` | нет | переносится |

Иконки у пунктов (есть в ТЗ) в макете нет — по договорённости не выводим.

## Ширины

- До 768 — пункты столбиком (макет 360).
- 768–1279 — наше: заголовок сверху, пункты в ряд.
- С 1280 — как 1920: заголовок крупно слева в колонке 390, пункты справа. Это новая точка
  `wide` в `_mixins.scss`: уже заголовок 80px не помещается.

Цвет чисел (Yellow `#c9a84c`) на фоне страницы — контраст 2.2:1, ниже AA даже для крупного
текста. Оставлено по макету.
