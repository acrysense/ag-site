# Контракт: «Карьерный шанс» (внутренние вакансии)

Черновик для согласования с бэкендом (Битрикс). Страница: `app/pages/career.html`, блоки —
`app/components/sections/career/*`. Витрина: `/dev/ui.html#story=career-list` (и
`vacancy-filters`, `career-steps`, `vacancy-modal`, `vacancy-apply`).

## Страница

Хлебные крошки, затем сетка `page-columns page-columns--start page-columns--split`:

1. `VacancyFilters` — фильтры (с 1024 — слева сверху; до 1024 — панель на весь экран).
2. `VacancyList` (класс `page-columns__main`) — список, страницы и окна вакансий.
3. `CareerSteps` (класс `page-columns__aside-end`) — «Как это работает» (с 1024 — слева под
   фильтрами, до 1024 — под списком).

После подвала, рядом с общими окнами, — `VacancyApply` (окно заявки и «Заявка принята»).

## Фильтры и адрес

Обычная GET-форма на адрес раздела. Группы: «Область» (`region[]`), «Город» (`city[]`),
«Направление» (`department[]`: работа в аптеке, управляющая компания, склад, работа в IT, работа с
клиентами, медицинская деятельность, e-commerce — набор правит админ); сортировка — скрытым полем (`hidden [{ name, value }]`), чтобы не терялась.
Пустые параметры в адрес не попадают.

| Поле | Что это |
| --- | --- |
| `groups[]` | `title`, `name`, `moreText` («Показать ещё 3»), `options[{ value, text, count, checked, extra }]` |
| `count` | сколько вакансий останется при выборе пункта; 0 — пункт неактивный |
| `extra` | пункт спрятан за «Показать ещё» (бэк отмечает пункты после первых 5–7; выбранные не прячет — если спрятал, скрипт сам откроет группу) |
| `resetUrl` | «Сбросить» — адрес без фильтров |
| `countUrl` | до 1024: `GET countUrl?<параметры формы>` → `{ "count": 5 }` для кнопки «Показать N вакансий» |
| `countText` | надпись кнопки при загрузке («Показать 24 вакансии», склонение на бэке) |

С 1024 выбор применяется сразу (переход по адресу). До 1024 — в панели, кнопкой «Показать N
вакансий»; закрыли панель без неё — выбор отменяется.

## Список

| Поле | Что это |
| --- | --- |
| `title` | «Карьерный шанс» (h1) |
| `sort` | `components/SortMenu`: `{ id, label, options [{ text, url, current }] }` — «Новые в начале / Старые в начале», как в новостях |
| `intro` | вводный текст (правит админ) |
| `introImage` | картинка к вводному тексту, необязательно: `{ src, srcset, alt }` — 386×250 справа от текста (отдавать 772×500), до 768 — над текстом во всю ширину |
| `filtersId`, `activeFilters` | кнопка «Фильтры · N» до 1024 (нет фильтров — не передавать `filtersId`) |
| `items[]` | вакансии (ниже) |
| `empty` | `{ text, resetText, resetUrl }` — ничего не найдено |
| `pagination` | общий `Pagination` (`pages`, `prev`, `next`, `total`, `totalText` «Всего:») |
| `applyId`, `applyText` | окно заявки и надпись «Откликнуться» |
| `loginUrl`, `loginText` | гость: вместо «Откликнуться» — «Войти, чтобы откликнуться» |

Вакансия: `id`, `url` (страница вакансии — без JS и для ссылки), `title`, `tags[{ text }]`
(направление, город), `address`, `params[{ label, value }]` (в окне вакансии; сейчас «Адрес» —
набор правит админ), `description` (HTML из визуального редактора: заголовки `h3` и списки —
«Обязанности», «Требования», «Мы предлагаем»), `applyTitle` («Провизор / фармацевт ·
ЛибертФарм, Минск» — подпись в окне заявки).

Порция — 9 вакансий (3 ряда по 3). 0, 1 и N вакансий — в витрине.

## Окно вакансии

Карточка (`data-modal-open="vacancy-<id>"`) открывает окно `vacancy-<id>` — оно выводится в
`VacancyList` после списка, по одному на вакансию на странице. Без JS «Подробнее» — ссылка на
`url`. «Откликнуться» открывает окно заявки вместо окна вакансии (не
поверх) и подставляет вакансию (`data-vacancy-apply`, `data-vacancy-apply-title`). Закрыли
заявку, не отправив, — снова открывается окно той же вакансии; после отправки — «Заявка
принята», затем список. Всё это делает JS по атрибутам — бэку достаточно вывести окна и кнопки
с этими атрибутами.

## Заявка

`POST action` (`multipart/form-data`, модуль Form, `docs/contracts/form.md`): `vacancy` (id),
`phone` (обязательно), `email` (из профиля, можно поправить), `resume` (файл, необязательно),
`message` (до 2000), `consent` = `Y` (обязательно), `sessid`.

- Данные из профиля (`profile { name, position }`) выводит бэк; фронт их не отправляет — бэк
  берёт ФИО и должность из сессии.
- Резюме: `accept=".pdf,.doc,.docx"`, `maxSize` (байты, 5 МБ). Фронт проверяет при отправке,
  **бэк проверяет то же самое** (размер, тип, вредоносные файлы).
- Телефон: цифры, пробелы, скобки, дефисы, «+»; от 7 до 15 цифр. Маски ввода нет.
- Ошибки полей — `{ ok: false, errors: { phone: "…" } }`, успех — `{ ok: true }`: заявка
  закрывается, открывается «Заявка принята», окно вакансии закрывается («Вернуться к
  вакансиям» — к списку).
