# Контракт: формы и «Предложить тему»

Вёрстка: поля — `components/Field`, `components/Checkbox`, отправка — `components/Form`,
окна — `layouts/SiteModals` (подключены на всех страницах после подвала). Витрина:
`/dev/ui.html#story=suggest-topic` (сервер имитируется: тема со словом «ошибка» — ошибка поля,
«сбой» — общая ошибка). Макет: Figma, 1920 — `4132:1034`, `4134:27265`; 360 — `4879:1361`,
`4880:1513`.

## «Предложить тему»

Открывается кнопкой в подвале (`site.footer.suggest.modal`); без JS кнопка — ссылка на
`suggest.url`. Тексты окна, полей, согласия и «Спасибо» — `site.modals.suggest`, правятся в
админке.

Поля: `name` (обязательно), `contact` (почта или телефон, обязательно), `topic`
(обязательно, до 2000 символов), `consent` = `Y` (обязательно), `sessid`.

## Запрос и ответ

`POST <action>` (обычный `FormData`, куки свои), заголовок `Accept: application/json`, в теле
`sessid` (`bitrix_sessid`, из `BX.bitrix_sessid()`, иначе из `data-sessid` формы).

Успех — статус 2xx и `{ "ok": true, "message": "…" }`: форма очищается и закрывается,
открывается окно «Спасибо», `message` читается скринридером.

Ошибка — `{ "ok": false, "errors": { "topic": "Такая тема уже предложена" }, "message": "…" }`
(статус 4xx): ошибки с именем поля — у поля, остальные и `message` — над кнопкой. Нет
JSON или 5xx — «Не удалось отправить. Попробуйте ещё раз.».

## Поведение (правила проекта)

- Проверка при отправке (форма короткая), не на каждый символ; при исправлении ошибка
  снимается.
- Ошибка — цвет, значок и текст; `aria-invalid`, `aria-describedby`; фокус на первое поле.
- Во время отправки кнопка неактивна, в ней значок загрузки, надпись та же; на форме
  `aria-busy`. Повторное нажатие не шлёт второй запрос.
- Изменённая форма при закрытии окна спрашивает «Закрыть форму?» (`site.modals.discard`).
