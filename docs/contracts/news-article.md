# Контракт: страница новости

Страница: `app/pages/news-article.html`. Вёрстка: `sections/news/NewsArticle` (заголовок,
обложка, текст, галерея, строка действий), текст — `components/Content` (класс `.content`),
галерея — `components/Gallery`, комментарии — `sections/shared/Comments`
(docs/contracts/comments.md). Слева — фильтры раздела и баннер, как в ленте
(docs/contracts/news-list.md).
Витрина: `/dev/ui.html#story=news-article`, `#story=content`, `#story=gallery`, `#story=comments`.

Макет: Figma, 1920 — `4652:11884` (новость — `4652:12003`, галерея — `4652:12790`,
комментарии — `4652:12134`). Мобильного макета нет — сделано нами (ниже).

## Раскладка

- С 1024: слева колонка 350 (фильтры, баннер), справа колонка до 1080: карточка новости и
  карточка комментариев через 10.
- До 1024: крошки и новость в белом блоке страницы без рамки, комментарии под новостью через
  32. Фильтров и баннера нет.

## Что выводит бэк

| Данные | Где | Примечание |
| --- | --- | --- |
| Заголовок | `h1.news-article__title` | |
| Обложка | `img.news-article__image` | 1040×341 (2x — 2080×682), обрезка по cover; без обложки блока нет |
| Подпись обложки | `figcaption.news-article__caption` | необязательна |
| Текст | `.content` | HTML из визуального редактора как есть (ниже) |
| Галерея | `components/Gallery` | фото 1040×500 (2x — 2080×1000), `alt` у каждого; одно фото — без стрелок и точек, пусто — блока нет |

| Комментарии | кнопка `#comments` | число комментариев; при отключённых можно не выводить |
| Нравится | `components/LikeButton` | `count`, `liked`, `url` |
| Дата | `time.news-article__date` | `datetime="YYYY-MM-DD"`, текст «ДД.ММ.ГГГГ» |

## Текст из редактора (`.content`)

Обёртки не нужны: стили висят на обычных тегах внутри `.content`.

- Заголовки `h2`–`h4`, абзацы, ссылки, `strong`/`em`, списки `ul`/`ol` (в том числе вложенные).
- Цитата — `blockquote` (фон и синяя линия слева).
- Картинка — `img` или `figure > img + figcaption`. Нужны `width`/`height` (пропорция до
  загрузки), ширину ограничивает колонка. Видео и карты — `iframe`/`video`, 16:9.
- Таблица — обычная `table` (с `thead` или без). Скрипт оборачивает её в прокручиваемую рамку
  (`div.content__table`, фокус с клавиатуры) — широкая таблица не ломает страницу.
- Раскрывающийся блок («аккордеон») — `details > summary + содержимое`. Значок-стрелку
  добавляет скрипт, без скрипта блок тоже раскрывается.
- Инлайн-стили и `font`/`color` из редактора лучше чистить на бэке: иначе они перебьют макет.

## Состояния

- Без обложки, без галереи, без текста — соответствующего блока нет, пустых отступов нет.
- Длинный заголовок и длинные слова переносятся (`overflow-wrap: anywhere`).
- «Скопировать ссылку»: Clipboard API; на 1,6 с поверх кнопок действий раскрывается вправо плашка
  «✓ Ссылка скопирована» (`.news-article__copied` внутри кнопки, текст — `copiedText`), строка не
  сдвигается; скринридеру — объявление. Если буфер недоступен — «Не удалось скопировать ссылку».
