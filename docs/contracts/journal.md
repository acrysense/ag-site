# Контракт: журнал (выпуски)

Страница: `app/pages/journal.html`. Вёрстка — та же лента раздела новостей
(`sections/news/NewsList` с `card: "journal"`), карточка — `sections/news/JournalCard`,
слева — фильтры раздела (`sections/news/NewsFilters`) и баннер (`sections/shared/SideBanner`).
Витрина: `/dev/ui.html#story=journal-list`.

## Раскладка

- С 1024: слева колонка 350 (годы, баннер), справа карточка с заголовком раздела
  («HR-дайджест»), сортировкой, сеткой выпусков и страницами.
- До 1024: заголовок, годы строкой «таблеток» с прокруткой вбок, сортировка полем во всю ширину,
  выпуски в 2 колонки, страницы. Годы выводит сама лента — `NewsList` с `filters` (те же данные,
  что у `NewsFilters` слева).
- Сетка: с 1280 — 3 в ряд (на 1920 — 360 через 60, ряды через 40), 1024–1279 — 2, планшет — 3,
  мобильный — 2. Промежуток между колонками на десктопе плавный: 60 на 1920.

## Что выводит бэк

| Данные | Где | Примечание |
| --- | --- | --- |
| Годы | `NewsFilters` (`years`) | как в разделе новостей (news-list.md): текущая — `current`; категорий у журнала нет |
| Заголовок | `list.title` | название раздела («HR-дайджест») |
| Сортировка | `list.sort { text, url }` | «Новые в начале» |
| Выпуски | `list.items[]` | ниже |
| Страницы | `list.pagination` | Pagination |
| Пусто | `list.emptyText` | «Выпусков пока нет» |

### Выпуск (JournalCard)

| Поле | Примечание |
| --- | --- |
| `title` | «HR-дайджест. Итоги 2025» |
| `readUrl` | «Читать» и клик по карточке (просмотр выпуска) |
| `file.url`, `file.sizeText` | «Скачать» — ссылка с `download`, размер строкой («1.2Гб») |
| `image.src`, `image.srcset` | обложка 1:1 — 360×360 (2x — 720×720), обрезка по cover |
| `date`, `dateText` | `YYYY-MM-DD`, «12.03.2025» |
| `likes`, `liked`, `likeUrl` | «Нравится» — как у новостей (LikeButton) |

## Страница выпуска

Страница: `app/pages/journal-issue.html` (открывается из «Читать» и по клику на карточку — `readUrl`).
Слева — то же, что в списке (`NewsFilters`, `SideBanner`), справа — выпуск
(`sections/news/JournalIssue`) и комментарии (`sections/shared/Comments`, `entity: "journal"`, см.
comments.md). Витрина: `/dev/ui.html#story=journal-issue`.

| Поле | Примечание |
| --- | --- |
| `title` | «HR-дайджест. Сентябрь 2026» — заголовок страницы (`h1`) |
| `date`, `dateText` | `YYYY-MM-DD`, «12.09.2026» |
| `pagesText` | «19 страниц» (склонение — на бэке), видно на мобильном |
| `file.url`, `file.typeText`, `file.sizeText` | PDF выпуска: «Скачать PDF · 3,3 МБ» и «Скачать» в полноэкранном режиме |
| `like` | LikeButton: `count`, `liked`, `url` — одна отметка на выпуск |
| `url` | ссылка для «Скопировать ссылку»; пусто — адрес страницы |
| `pages[]` | страницы по порядку, ниже |

### Страница (`pages[]`)

| Поле | Примечание |
| --- | --- |
| `src`, `width`, `height` | картинка страницы 16:9 (1536×864 или больше) — и в ленте, и на весь экран |
| `srcset` | необязательно: 1200 и 2400 по ширине |
| `thumb`, `thumbSrcset` | миниатюра 224×126 (2x для 112×63) |
| `alt` | «Страница 3» или текст страницы, если есть |

Страницы — картинки, которые бэк готовит из PDF (по странице на картинку). Одна страница — без
стрелок, счётчика и миниатюр. Без скрипта страницы листаются пальцем и колесом, клик открывает
картинку.
