# Контракт: журнал (выпуски)

Страница: `app/pages/journal.html`. Вёрстка — та же лента раздела новостей
(`sections/news/NewsList` с `card: "journal"`), карточка — `sections/news/JournalCard`,
слева — фильтры раздела (`sections/news/NewsFilters`) и баннер (`sections/shared/SideBanner`).
Витрина: `/dev/ui.html#story=journal-list`.

## Раскладка

- С 1024: слева колонка 350 (категории журналов, годы, баннер), справа карточка с заголовком
  раздела («HR-дайджест»), сортировкой, сеткой выпусков и страницами.
- Сетка: с 1280 — 3 в ряд (на 1920 — 360 через 60, ряды через 40), 1024–1279 — 2, планшет — 3,
  мобильный — 2. Промежуток между колонками на десктопе плавный: 60 на 1920.

## Что выводит бэк

| Данные | Где | Примечание |
| --- | --- | --- |
| Категории, годы | `NewsFilters` | как в разделе новостей (news-list.md): текущая — `current` |
| Заголовок | `list.title` | название категории журнала |
| Сортировка | `list.sort { text, url }` | «Новые в начале» |
| Выпуски | `list.items[]` | ниже |
| Страницы | `list.pagination` | Pagination |
| Пусто | `list.emptyText` | «Выпусков пока нет» |

### Выпуск (JournalCard)

| Поле | Примечание |
| --- | --- |
| `title` | «HR-дайджест. Итоги 2025» |
| `readUrl` | «Читать» и клик по карточке (просмотр выпуска) |
| `file.url`, `file.sizeText` | «Скачать» — ссылка с `download`, размер строкой («1.2Гб») |
| `image.src`, `image.srcset` | обложка 1:1 — 360×360 (2x — 720×720), обрезка по cover |
| `date`, `dateText` | `YYYY-MM-DD`, «12.03.2025» |
| `likes`, `liked`, `likeUrl` | «Нравится» — как у новостей (LikeButton) |
