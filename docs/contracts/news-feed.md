# Контракт: блок «Новости холдинга» на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/NewsFeed`,
карточка — `app/components/sections/shared/NewsCard`, отметка «Нравится» —
`app/components/components/LikeButton`. Витрина: `/dev/ui.html#story=news-feed`.

## Что выводит бэк

Список последних новостей раздела «Новости холдинга», **6 штук**: на мобильном видны все 6
(3 ряда по 2), на десктопе — первые 5 в один ряд. Если новостей нет, блок не выводится вовсе.

| Поле | Где в разметке | Обязательно | Примечание |
| --- | --- | --- | --- |
| Заголовок блока | `.news-feed__title` | да | правится в админке |
| Ссылка «Показать все» | `.news-feed__all[href]` | нет | без ссылки строка не выводится |
| Ссылка на новость | `.news-card__link[href]` | да | кликабельна вся карточка |
| Заголовок новости | `.news-card__link` | да | до 3 строк на мобильном, 2 на десктопе, дальше «…» |
| Анонс | `.news-card__excerpt` | нет | до 3 строк, дальше «…»; место под 3 строки есть всегда |
| Картинка | `.news-card__image` | нет | квадрат, `object-fit: cover`; нужны `width`, `height`, `srcset`. Пропорция 1:1, как в «Акциях», — обложки взаимозаменяемы |
| Дата | `time.news-card__date[datetime]` | да | `datetime` — `YYYY-MM-DD`, текст — `ДД.ММ.ГГГГ` |
| Комментарии | `.btn[href]` | да | ссылка на комментарии новости, число; 0 — без числа |
| «Нравится» | `.like-button` | да | число, отмечено ли текущим пользователем, адрес POST |

Картинка декоративная (`alt=""`): название новости уже есть в ссылке. Ресайз — на бэке:
квадрат 330px и 660px для `srcset` (на мобильном карточка до ~50% экрана, на десктопе до 300px).

## «Нравится»

```html
<button class="btn btn--light btn--s like-button" type="button" aria-pressed="false"
        data-module="LikeButton" data-path="components" data-like-url="/ajax/news-like.php?id=123">
```

- `aria-pressed="true"`, если текущий пользователь уже отметил новость.
- По клику уходит `POST` на `data-like-url`, тело — `FormData`: `liked` (`Y` / `N`) и `sessid`
  (`bitrix_sessid`, берётся из `BX.bitrix_sessid()`, иначе из `data-sessid` кнопки).
- Ответ — JSON: `{ "liked": true, "count": 18 }`. Ошибка — любой статус кроме 2xx: отметка
  возвращается как была, пользователь получает сообщение.
- Нужен ответ бэка: гость может ставить отметку или кнопка для него неактивна?

## Иконки

Иконки подключаются из SVG-спрайта: `<svg><use href="#icon-comment"></use></svg>`. Спрайт
собирается сборкой и вставляется в начало `body` скриптом `app.js`. Нужно подтвердить, что
шаблон Битрикса подключает этот скрипт на всех страницах — в проекте `ag` спрайт не заработал.
