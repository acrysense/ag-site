# Контракт: «Галерея живой заботы» на главной

Черновик для согласования с бэкендом (Битрикс). Вёрстка: `app/components/sections/home/Leaders`,
вкладки — `app/components/components/Tabs`, карусель — `app/components/components/Carousel`.
Витрина: `/dev/ui.html#story=leaders`.

Макет: Figma, главная 1920 — узел `4615:43127`, 360 — `4865:1668`. Последний блок главной.

## Что выводит бэк

Заголовок, ссылка на всех лидеров и списки-вкладки: «Лидеры месяца», «Фарм-лидеры».

- «Фарм-лидеры» по ТЗ скрыты по умолчанию, админ включает сам. Скрытый или пустой список бэк
  не выводит. Один список — без вкладок. Нет списков — блок не выводится.
- Десктоп: карусель, на экране 5 карточек (4 на 1024–1279), стрелки листают по экрану; все
  карточки помещаются — стрелок нет. Мобильный: первые 6 сеткой и «Показать все».

| Поле | Где в разметке | Обязательно | Примечание |
| --- | --- | --- | --- |
| Заголовок блока | `.leaders__title` | да | правится в админке (ТЗ) |
| Ссылка на всех | `.leaders__title a`, `.leaders__all` | нет | «Показать все» — только на мобильном, как в макете |
| Название вкладки | `.tabs__tab` | да | |
| Ссылка на сотрудника | `a.leaders__card[href]` | нет | ТЗ: клик — в карточку сотрудника |
| Фото | `.leaders__photo` | нет | квадрат; нет фото — серая заглушка с силуэтом |
| Имя | `.leaders__name` | да | переносится |
| Должность | `.leaders__position` | нет | |
| Заслуга | `.leaders__award` | нет | ТЗ: «за какие заслуги»; в макете 360 её нет — на мобильном скрыта |
| Значок заслуги | `.leaders__award-icon` | нет | один из спрайта: `award-trophy`, `award-podium`, `award-leaf`, `award-pro` |

Фото — квадрат 300px на 1920, для 2x — **600×600**, `object-fit: cover`. На мобильном круг.
Пропорция 1:1, как у обложек новостей и акций. Ресайз и сжатие — на бэке (ТЗ: «не мылить»,
никакого `transform: scale` у фото).

Вкладки — WAI-ARIA Tabs: `role="tablist"`, панели `role="tabpanel"` с `hidden`, клавиатура —
стрелки, Home, End.
